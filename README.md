# Lake Powell Inflow Comparisons
Comparisons of Lake Powell inflow Projections and scenarios

The code LakePowellForecastHistory.ipynb contains 2 folders :
1.	 2-5 year plan compares our scenarios to 24 Month study
2.	Volatility compares year to year drops in flow to demonstrate volatility
3.	Decision Frequency model using crss outputs of a monthly operations decision point to an annual decision point
