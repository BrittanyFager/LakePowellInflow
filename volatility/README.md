## Lake Powell Inflow Comparisons
Comparisons of Lake Powell inflow projections and hydrologic scenario behavior.

This repository analyzes Colorado River natural flow ensembles, Lake Powell storage vulnerability, and year‑to‑year flow volatility using datasets from Salehabadi et al. (2024) and the U.S. Geological Survey (2018). The workflow consists of two Python scripts that must be run in order.

#📂 Data Sources
HydrologyScenarios.xlsx
Streamflow ensembles from Quantifying and Classifying Streamflow Ensembles Using a Broad Range of Metrics for an Evidence‑Based Analysis: Colorado River Case Study (Salehabadi et al. 2024).
Each sheet contains annual natural flow traces (MAF) for a specific ensemble.

Streamflow ensembles

Lake_Powell_2018_ElevAreaCap_calc.csv
Elevation–area–capacity table for Lake Powell (USGS 2018).
Used to convert simulated storage (MAF) → elevation (ft).

Learn more:

Elevation–storage curves

1. MassBalance_StorageSimulation.py
This script must be run first.

It performs the core hydrologic and reservoir calculations:

Reads all ensembles from HydrologyScenarios.xlsx

Builds a long‑format inflow table

Simulates Lake Powell storage under multiple release volumes

Converts storage → elevation using the USGS capacity table

Identifies ensembles that fall below 3490 ft (5.49 MAF)

Produces bar charts showing ensemble vulnerability

Computes all year‑to‑year inflow pairs and writes:

2. AnnualFlowPlot_and_DropAnalysis.py
This script contains two major analyses, both of which require
AllHydrology_YearToYearPairs.csv generated by the MassBalance script.

A. Annual Flow Distribution (0.5‑MAF bins)
This section:

Extracts all annual flows

Removes zero‑flow artifacts

Bins flows into 0.5‑MAF increments

Counts how many ensembles produce flows in each bin

Plots ensemble representation across the 3–12.5 MAF range

Highlights reference flows such as:

6.0 MAF (example annual release)

12.5 MAF (2000–2020 average natural inflow)

B. Year‑to‑Year Drop Magnitude Analysis
This section analyzes volatility in natural inflows:

Filters to negative year‑to‑year flow changes

Computes drop magnitudes

Bins drops into 1‑MAF intervals

Counts how many ensembles experience drops of each size

Highlights historically significant drops (e.g., 2005–2006, 2019–2020, 2025–2026)

🔄 Script Execution Order (Important)
