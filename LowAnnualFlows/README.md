# Low Flow Analysisy
 
## How low could natural flow at Lee Ferry get, and how many hydrology ensembles agree?
 
This folder contains a notebook that finds the lowest single-year natural flow in each ensemble of Lee Ferry hydrology and summarizes how many ensembles agree that flows could get that low. The results are shown as an "agree-o-gram."
 
### Folder Contents
 
- **lowflows.ipynb**  
  Reads every ensemble sheet in `HydrologyScenarios.xlsx`, finds the lowest single-year flow in each trace, then the lowest flow across all traces in each ensemble. Each ensemble is counted once. Ensembles are grouped into flow bins (1 MAF wide by default), and the notebook builds cumulative counts: the number of ensembles whose lowest flow is in a given bin or lower. It also pulls the three lowest years from the historical record (`Hist` sheet) and plots them alongside the ensemble results.
- **HydrologyScenarios.xlsx**  
  Multiple ensembles of possible natural flow at Lee Ferry (annual flow in MAF, one sheet per ensemble, one column per trace) generated by Salehabadi, H., et al. (2024). Non-ensemble sheets (ReadMe, AvailableHydrologyScenarios, ScenarioListForAnalysis, AvailableMetrics, MetricsForAnalysis, Heatmap) are skipped, and the `Hist` sheet is used for historical lows.
- **Results/**  
  Created automatically when the notebook runs. See below.
---
 
### Settings
 
Set at the top of the notebook:
 
| Setting | Default | Meaning |
|---|---|---|
| `MIN_VALID_FLOW` | 0.5 MAF | Single-year flows below this are treated as unrealistic and discarded before finding minimums |
| `PLOT_MAX_FLOW` | 8 MAF | Top of the plotted y-axis; bins at or above this are not plotted |
| `bin_width` | 1.0 MAF | Width of each flow bin (use 0.5 for finer resolution) |
 
---
 
### Output Files (in `Results/`)
 
- **LowestFlowYear_ByTrace.csv**  
  Lowest valid single-year flow for every trace in every ensemble, with the year and bin.
- **LowestFlowYear_ByEnsemble.csv**  
  One row per ensemble: its lowest flow across all traces, with the trace and year it occurred.
- **LowestYear_ByEnsemble_Sorted.csv**  
  The same ensemble minimums, ranked lowest first.
- **EnsembleAgreement_LowestFlowYear.csv**  
  Number of ensembles per bin (`NumEnsembles`) and the cumulative count (`CumEnsembles`) used for the agree-o-gram.
- **Counts_LowestFlowYear.csv**  
  Number of trace-level minimums per bin, for reference.
---
 
### How to Read the Agree-o-gram
 
- The y-axis is natural flow at Lee Ferry (MAF), in bins.
- The x-axis is the number of ensembles (out of 22) whose lowest single-year flow reaches that bin or lower.
- A bar of 10 at the 4-5 MAF bin means 10 of 22 ensembles agree flows could get as low as 4-5 MAF.
- Historical lows from the `Hist` sheet are labeled on the right side of the plot.

## Run Online (No Installation Required)
 
If you do not want to install Python or Jupyter locally, you can run `lowflows.ipynb` online using Binder, a free service from Project Jupyter.
 
1. Go to [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/BrittanyFager/LakePowellInflow/HEAD)
2. On the left side of the environment you will see the folders shown on this GitHub repository, along with the README and `requirements.txt`.
3. Open this folder and double-click `lowflows.ipynb` to run and edit it in the online instance.
Requirements: `pandas`, `numpy`, `matplotlib`, `openpyxl` (for reading the Excel file).
